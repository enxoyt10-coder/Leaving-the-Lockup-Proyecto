# Leaving the Lockup

Un juego de decisiones y escape de prisión inspirado en el estilo clásico de Henry Stickmin.

## 📌 Descripción
El jugador despierta en una celda y debe tomar una serie de decisiones para lograr escapar. Cada elección conduce a distintos resultados, combinando humor absurdo, cinemáticas y mecánicas interactivas.

## 🕹️ Cómo Jugar
1. Ve a la carpeta `Ejecutable/`.
2. Ejecuta el archivo `Leaving the Lockup.exe`.
3. Navega por el menú principal y toma decisiones en el juego haciendo clic con el ratón.

## 🛠️ Tecnologías Utilizadas
* **Motor:** Unity 6
* **Lenguaje:** C#
* **Interfaz:** TextMeshPro / Unity UI

## 📂 Estructura del Proyecto
* `Assets/`: Código fuente, animaciones, sprites y escenas del proyecto.
* `Ejecutable/`: Versión compilada del juego lista para jugar en Windows.
